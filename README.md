# FrameTree

图片优先的 AI 影视分镜工作台。基于 React + TypeScript + React Flow，把故事、场景和镜头组织成可拖拽、缩放、折叠的无限画布。

## 本地运行

需要 Node.js 22.12+（建议 22 LTS）。

```sh
npm ci
npm run dev
```

打开终端显示的本地地址。

```sh
npm test       # 树结构、折叠、布局和项目格式校验
npm run build # TypeScript 检查与生产构建
npm run preview
```

## 已实现

- 图片树：故事 → 场景 → 镜头，支持任意深度的分支、拖动、分支折叠与自动布局。
- 无限画布：平移、缩放、小地图、适应视图、节点搜索定位。
- 分镜属性：标题、类型、景别运镜、时长、画面脚本与 AI 提示词。
- 图片导入：JPG / PNG / WebP，单图最大 100 MB；多选时第一张替换当前图片，其余添加为同级节点。
- 大图处理：导入时生成最长边 960px 的 WebP 缩略图；原始 Blob 存放于 IndexedDB，原图查看时才创建临时 URL，关闭后释放。
- 自动保存：浏览器 IndexedDB 本地持久化，项目与原图不上传服务器。
- 项目导入导出：`.frametree.json` 包含画布、缩略图与原图；导入限制 300 MB / 2000 个节点，并校验树关系。
- Markdown 脚本导出：按父子顺序输出脚本、时长、运镜与生成提示词。
- GitHub Actions：自动运行测试和生产构建。

## 使用流程

1. 选中故事节点，点击「添加子节点」建立场景和镜头。
2. 在右侧上传图片，填写画面脚本、景别、运镜和时长。
3. 添加不同的分支探索视觉方案；折叠暂时不用的分支。
4. 双击图片查看原图，通过加减按钮缩放，滚动查看细节，Esc 关闭。
5. 复制提示词到你使用的 AI 生成工具；导出项目备份，或导出 Markdown 脚本交接。

删除节点会同时删除其后代，需要确认；根节点不可删除。导入项目会替换当前画布，建议先导出当前项目。浏览器清理站点数据也会清除本地素材，请定期导出备份。

## 架构

- `src/main.tsx`：画布、编辑器、原图查看、文件交互。
- `src/model.ts`：项目模型、树操作、布局、导入校验。
- `src/storage.ts`：IndexedDB、缩略图生成、下载。
- `src/style.css`：暗色创作工作台与响应式布局。

画布启用 React Flow 的可见元素渲染优化，节点组件使用 React.memo。大图仍需浏览器解码；100 MB 文件限制并不保证所有超高像素图片都能在低内存设备上导入。JSON 导出会把原图编码到内存中，极大项目应在后续迁移到流式 ZIP 与对象存储方案。目前不提供深度缩放瓦片或服务端图片金字塔，也尚未进行千节点压力测试。

当前是浏览器单机 MVP，尚未接入 AI 图片/视频生成 API、多人协作、云端素材库、撤销重做或视频时间线。建议后续将 AI 任务调度与密钥管理放在服务端，前端通过任务状态更新画面节点，避免把 API Key 放进浏览器。
